# Project Statement

## Problem Statement
Many students and young professionals lose track of their daily expenses because tracking money manually is confusing. The problem is that there isn't a simple, fast tool to quickly log incomes and expenses and instantly see how much money is left over.

## Scope of the Project
This project is a Command Line Interface (CLI) application that allows users to record their incomes and expenses. It automatically calculates total balances, groups spending by category, and saves the data to a local JSON file so records aren't lost when the app closes. 

## Target Users
*   **College Students:** Who need a quick, distraction-free way to track their pocket money and daily expenses.
*   **Beginner Programmers:** Who want to see how basic Python concepts like loops, dictionaries, and classes can build a real-world tool.

## High-Level Features
1.  **Transaction Logging:** Users can add incomes and expenses with descriptions and categories.
2.  **Data Persistence:** The app automatically saves and loads data using a JSON text file.
3.  **Financial Reporting:** The system calculates a live balance and generates a formatted text report showing total money in, total money out, and spending breakdowns.
